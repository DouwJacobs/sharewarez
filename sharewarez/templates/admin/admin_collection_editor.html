How to write smart rules JSON

Use one JSON object with a match mode and between 1 and 20 conditions. Choose all when every condition must match, or any when one condition is enough.

{
  "match": "all",
  "conditions": [
    {"field": "genre", "operator": "equals", "value": "RPG"},
    {"field": "rating", "operator": "gte", "value": 80}
  ]
}

Fields and operators

Value typeFieldsOperatorsExample value
Text name, library, genre, theme, tag, platform, developer, publisher equals, not_equals, contains, not_contains "RPG"
Number rating, release_year, size, downloads equals, not_equals, gte, lte, gt, lt 80
Boolean has_updates, has_extras equals true or false

More examples

Games from either of two platforms:

{
  "match": "any",
  "conditions": [
    {"field": "platform", "operator": "equals", "value": "Windows"},
    {"field": "platform", "operator": "equals", "value": "Linux"}
  ]
}

Recent games with updates:

{
  "match": "all",
  "conditions": [
    {"field": "release_year", "operator": "gte", "value": 2020},
    {"field": "has_updates", "operator": "equals", "value": true}
  ]
}

JSON rules: use double quotes around names and text, lowercase true/false without quotes, and no comments or trailing commas. Text comparisons are case-insensitive. Size uses the stored byte count. Sorting and result limits are configured in the fields below, not inside this JSON.

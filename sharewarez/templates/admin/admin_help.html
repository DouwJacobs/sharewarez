Quick startCreate a library and make its games available.
  1. 1
    Create a library

    Open Game Libraries, choose a clear name, and select the platform that best matches the collection.

  2. 2
    Start a scan

    Select a folder within the configured storage roots. {{ site_title }} indexes folder or file names and attempts to match them with IGDB.

  3. 3
    Resolve unmatched entries

    Use the unmatched list to search IGDB manually or add an entry without an IGDB match.

  4. 4
    Review the library

    Confirm artwork, metadata, paths, and download behavior before inviting users.

Tip: Accurate platform selection and clean game names substantially improve automatic matching.
Libraries, scanning, and metadataOrganize content and maintain accurate matches.

Library management

  • Each library represents a platform or logical collection.
  • Libraries can be reordered, edited, rescanned, or removed.
  • Removing a database entry and deleting files from disk are separate operations.

Scan behavior

  • Folder-based and file-based collections are supported.
  • Release-name filters improve filename parsing.
  • Use “Remove missing” only after confirming that all storage paths are mounted.
  • Scan jobs, unmatched entries, and the image queue are managed from Scan Management.

Local metadata

  • sharewarez.json can preserve an IGDB match beside a game.
  • Local covers and screenshots can take priority when enabled.
  • HowLongToBeat estimates are optional and use the configured request delay.

Updates and extras

  • Configured Updates and Extras subfolders are indexed separately.
  • They appear as optional files on the game-details page.
  • They are excluded from the main game payload when recognized.
DownloadsDirect files, streamed folders, status, and administration.

How files are delivered

  • A game stored as one file, including an existing ZIP, is served directly.
  • A multi-file game folder is streamed as a ZIP on demand; {{ site_title }} does not need to create a temporary archive first.
  • Metadata files such as .nfo, .sfv, file_id.diz, and sharewarez.json do not force a single-file game to be repackaged.

Managing requests

  • Game names link back to their game-details pages.
  • Users can cancel pending legacy jobs or retry failed/cancelled requests when the source still exists.
  • Administrators can filter by user or status and apply bulk actions.
  • Administrative actions are available in the audit log.
Paths: Downloads are allowed only from configured storage roots. A retry fails when the stored source path no longer exists or is inaccessible.
Users and access controlRoles, invitations, whitelist, and search permissions.

Accounts and roles

  • Administrators manage account state, roles, verification, profiles, and passwords.
  • Administrator routes enforce authorization on the server, not only in the interface.
  • Review access when disabling or deleting an account.

Registration control

  • The whitelist permits approved email addresses to self-register.
  • Invitations provide controlled registration outside the whitelist.
  • User-to-user invitations and quotas are configurable in Server Settings.

Global search

  • All signed-in users can search games and libraries.
  • Only administrators receive user and settings results.
  • Ctrl + K opens search from anywhere.

Security basics

  • Use HTTPS outside a trusted local network.
  • Keep the application secret and integration credentials out of source control.
  • Review security and audit events in System Logs.
Integrations and notificationsIGDB, SMTP, Discord, newsletters, and themes.

IGDB

Configure credentials and test connectivity before scanning. Matching and artwork retrieval depend on a working IGDB connection.

SMTP

Email supports verification, password resets, invitations, and newsletters. Use the integration test after changing server, port, authentication, or TLS settings.

Discord

The current webhook integration supports automatic new-game notifications and optional manual notifications. Settings for other event types may be present but are not all implemented yet.

Themes

Themes may override selected assets and fall back to the default theme for missing files. Review custom JavaScript before installation. See the theme guide.
